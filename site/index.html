The reader

Built for reading first. Writing when you need it.

Open a file or a whole folder. Margin renders it beautifully, then gets out of the way until you want to mark something.

01

Select text to mark it up

Highlight in four colours, pin a sticky note to a passage, or drop a bookmark on any paragraph. Notes sit in the margin like paper.

  • Highlights in yellow, green, pink and blue
  • Sticky notes, each with its own colour
  • Bookmarks with optional labels ⌘D
02

Everything you marked, in one place

The Marks tab lists every bookmark, note and highlight in the document. Click one to jump straight to it.

  • Folder library with a filter ⌘K
  • Outline that tracks where you are
  • Reading position remembered per file
03

Edit the page, not the syntax

Type straight into the rendered document, with Markdown shortcuts as you go. Saving rewrites only the blocks you touched; everything else is kept byte for byte.

  • Edit mode ⌘E
  • Raw Markdown when you want it ⌘/
  • Faithful save ⌘S
The format

It is still plain Markdown. Your marks travel with the file.

No database, no sidecar, no lock-in. Annotations are ordinary text that any editor can read, and one click strips them for a clean copy.

Local by design

Your files stay yours. Nothing is uploaded.

Margin is a small local server and a web page. It runs on your machine, talks only to your machine, and can only touch the folder you opened.

Loopback only

Serves on 127.0.0.1 and rejects requests from other websites.

Confined to one folder

Reads and writes only Markdown files inside the folder you opened. Hidden files are never served.

Safe to open anything

Rendered Markdown is sanitised, so an untrusted file cannot run scripts.
